*** ----- *** INSTALL PLAYWRIGHT *** ----- ***

Create virtual machines.

1. Create the folder where the virtual machine will be.
2. Create virtual machine: 
   python -m venv vm_name
3. Enter to the sub-folder bin and run:
   source ./bin/activate

Install playwright.

1. Install playwright.
   pip3 install pytest-playwright
2. Confirm that playwright is installed.
   pip list
3. Install all the playwright complements.
   playwright install

*** ----- *** COMMANDS *** ----- ***

- pytest file.py::test_name
:: Coloca dos puntos 2 veces para indicar la función del archivo py que se va a ejecutar.

- playwright codegen URL
Agrega la URL del sitio web después de "codegen".

- playwright show-trace path/trace.zip
Muestra el paso a paso de la ejecución de las pruebas en un "viewer" especial.

- pytest path/file.py -s -v
Muestra el resultado de cada test que tenga @pytest.mark.

- pip install openpyxl
Plugin para leer/escribir en archivos Excel.

** CREATE SIMPLE REPORTS **

Install pytest-report:
- pip install pytest-report

Create a simple report:
- pytest path/file.py --html=/path/basic-report.html

** CREATE REPORTS with CHARTS **

Install pytest reporter:
- pip install pytest-reporter-html1

Create the report with charts:
- pytest path/file.py --template=html1/index.html --report=/path/report-charts.html
